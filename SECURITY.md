# Security reporting

Please do not disclose credentials, personal Vault data, private research material or Zotero contents in an issue. During private testing, report suspected vulnerabilities privately through the repository owner or an existing authorized contact. No response-time guarantee is made.

Configuration, outbound data flows, SecretStorage usage and current verification limits are documented in [the security guide](docs/SECURITY.md). The desktop preview is not a security-audited release.
