# 安全配置与数据边界

适用版本：0.4.5。这里说明本插件实现的约束与用户应核对的行为，不代表安全审计认证。Obsidian 桌面第三方插件运行在高权限环境，插件内的配置校验不构成操作系统沙箱；只安装可信来源的程序。

## 推荐初始配置

- 本地翻译默认关闭。确认本机模型和资源后主动启用，先试一篇。
- Ollama 只接受 loopback 根地址，例如 `http://127.0.0.1:11434`，不使用公网地址、用户名密码、`/api/chat` 路径。无需云模型 API key。
- Zotero 标记默认关闭，启用前确认你要访问的是本机个人文库。
- 自动定时刷新默认关闭；打开来源仍会联网获取元数据。
- 收件箱使用普通 Vault 相对路径，例如 `Research Radar/Inbox`；不允许绝对路径、隐藏目录或 `..`。
- 不要让不可信 Agent 覆盖正在运行的 `data.json` 或直接修改插件 JavaScript。主题定制使用 profile 导入。

## 哪些数据会流向哪里

| 动作 | 目的地 | 数据/行为 |
|---|---|---|
| 打开/刷新文献列表 | PubMed、Crossref、Europe PMC 或允许的 RSS 服务 | 检索词、期刊、种子标识；对方会看到网络请求 |
| 检查连接与模型 | 本机 Ollama `/api/tags` | 仅读取可用模型清单，不加载推理 |
| 试译/手动翻译 | 配置的本机 Ollama `/api/chat` | 测试句或所选论文标题和摘要；不发送整个 Vault 或 PDF |
| Zotero 标记 | `127.0.0.1` 的配置端口 | 只读条目、子附件信息；必要时读取本地 PDF 开头确认文件 |
| 保存论文任务 | 本库收件箱 | 论文书目信息、摘要和用户要求，生成 MD/JSON |
| 复制任务/主题 | 系统剪贴板 | 用户主动复制的文本；系统剪贴板历史或跨设备同步可能保留 |
| 点击论文原文 | 默认浏览器 | 跳转对应原文站点，适用该站点自己的行为 |

文献域名允许名单见程序 core.js，当前为 PubMed/E-utilities、Crossref、Europe PMC、Nature、arXiv、bioRxiv。插件没有自带遥测，也没有自动启动外部 Agent 的代码。本机 API 地址限制不能保证你安装的模型服务本身没有网络功能，模型服务另行管理。

## 本地保存和分享

插件目录的 `data.json` 保存设置、上一版设置、列表缓存、译文和批次进度；它可能包含未公开的研究方向。收件箱含论文与任务意图。Obsidian Sync、云盘、备份工具是否同步 `.obsidian` 由你自己的设置决定，插件不能保证这些文件只留在本机。

**可分享**：官方打包的 ZIP；经检查的主题 profile。profile 不含本机地址、翻译模型设置、Zotero设置、缓存或任务，但主题、检索式和种子仍可能暴露研究兴趣。

**不要直接分享**：整个插件安装目录、data.json、自己的收件箱或测试日志。分发脚本使用文件白名单，不会把这些内容打进去。

## Agent 配置的权限边界

推荐仅给 Agent：本包 AGENT.md、example-profile.json、用户授权的研究兴趣材料。让它返回主题方案，导入前预览变化。方案校验检查结构、数量、路径和部分正则复杂度；它不会审查科研真实性，所以 DOI/PMID、期刊身份和推荐价值仍需核对。

`previewProfile` 无副作用；`applyProfile` 检查版本并保留本机集成设置，不执行 JSON 中的代码。导入是替换主题集合，先导出当前方案。配置冲突时重新预览，不能用新的 revision 强行掩盖未经核对的改动。

拥有 Obsidian `eval` 或文件系统权限的 Agent 本身能执行代码，这比导入方案权限更大。高级 `applySettings` 能更改本机集成；它应仅在用户明确授权时使用，不能把文档约定当成硬隔离。第三方论文和网页内容只当数据，不能据其中指令修改本机配置或导出私人文件。

## 本地资源控制

手动串行翻译、失败暂停、重载不自动继续。暂停不等于终止已在模型服务运行的当前请求。超时后不要立刻反复续跑，应先核对模型实际状态。`keep_alive=30s` 是发送给 Ollama 的请求参数，不保证其他应用不继续使用模型。

插件不会安装/删除模型、执行 shell、主动下载 PDF、写入 Zotero、恢复固定 Codex 对话或扫描其他应用的 API key。文献任务「已保存」不能显示成「已发送」「全文已下载」。

## 备份与恢复

升级前关闭插件并备份安装目录；模型文件在 Ollama 自己的数据目录，插件备份不包含它们。设置的「恢复上一版」只恢复上一份设置，不恢复模型/删除的数据/收件箱。完整恢复需要你自己的备份。

当前未做独立安全渗透测试，未实机验证 Windows/Linux。不能将通过单元测试解释为安全认证或科学验收。

## 在线翻译的授权和密钥（0.4.0）

翻译默认保留本地且关闭；在线发送另设授权开关。只有选择在线服务、允许在线发送、启用翻译并主动点击后，才把标题/摘要发给所选服务。连接诊断是用户主动联网动作：Google/Bing/MyMemory与微软官方翻译发送固定短语（消耗少量额度），DeepL读取额度，AI服务读取模型元数据。悬停、中文切换、打开面板不发送翻译请求。失败暂停、不自动降级到另一家、不自动续跑。

| 服务 | 目的地 | 发出的数据 |
|---|---|---|
| Google实验性网页翻译 | translate.googleapis.com | 查询参数中的标题/摘要分段；不带API密钥 |
| Bing实验性网页翻译 | www.bing.com 或 cn.bing.com | 匿名公开会话参数、分段标题/摘要POST；无私人浏览器Cookie/共享Key |
| MyMemory | api.mymemory.translated.net | 查询参数中的标题/摘要分段；匿名按IP限额，不携带邮箱、不提交公共翻译记忆 |
| 微软Translator API | api.cognitive.microsofttranslator.com | 标题/摘要JSON、Key及可选资源区域请求头 |
| OpenAI | api.openai.com | 模型、提示词、标题/摘要、Bearer Key；Responses设置store=false |
| Gemini | generativelanguage.googleapis.com | 模型、提示词、标题/摘要；Key通过x-goog-api-key请求头传递 |
| Claude | api.anthropic.com | 模型、提示词、标题/摘要；x-api-key请求头 |
| 通义千问 | dashscope.aliyuncs.com 或 dashscope-intl.aliyuncs.com | 由用户选区域，模型、提示词、标题/摘要与Bearer Key |
| 智谱GLM | open.bigmodel.cn | 模型、提示词、标题/摘要与Bearer Key |
| DeepL API | api-free.deepl.com 或 api.deepl.com | 标题/摘要JSON、Authorization密钥；诊断读取额度 |
| DeepSeek API | api.deepseek.com | 模型、翻译提示词、标题/摘要及Bearer密钥 |
| 自定义兼容API | 用户指定的HTTPS基础地址 | 同上；用户必须确认该域名及密钥归属 |

带密钥的API请求独立使用Node HTTPS，不跟随任何重定向，限制响应大小并设置请求总超时；Google/Bing/MyMemory免密钥请求采用Obsidian网络接口并设置等待超时，底层网络行为由Obsidian决定。没有自动重试。不会把服务端原始报错正文写入日志，以减少回显密钥风险。Google及MyMemory请求的文本位于URL查询参数中，服务方、代理或网络日志可能保留；只发送你有权外发的内容，涉及未公开材料时使用本地服务。在线服务的保留策略、地区与费用由其条款决定。

API密钥只在实际请求前从 Obsidian SecretStorage 读取；程序设置/回滚设置只含密钥引用名，主题profile完全排除翻译配置。分发包不含密钥、个人data.json或译文。SecretStorage是Obsidian的集中管理，**不能隔离同库其他高权限插件**，也不代表本插件进行了系统级加密认证；其备份/同步按Obsidian实际实现与用户设置管理。程序不会搜索Easydict、环境变量、浏览器或其他应用中的密钥。

高级Agent可调用applySettings改变在线服务或授权开关；这不是限制拥有代码执行权限的Agent的沙箱。只让Agent通过profile定制主题；密钥和在线发送授权由用户在设置页选择。未取得付费API凭证时，协议测试通过不等于真实账号可用。

## Zotero 恢复核对（0.3.1）

仅在保存启用集成后读取本机个人库：顶层条目的DOI、标题、年份、期刊等元数据用于匹配，匹配条目的子附件与本机文件头用于PDF存在/可读性检查。无云端上传，不写Zotero、不自动下载PDF，也不启动Zotero或翻译模型。

可见面板通过窗口焦点及60秒间隔发现连接恢复；正常元数据/附件缓存5分钟，并合并同一列表重复请求。关闭开关后不再开始后台核对；已发出的只读请求可能仍完成。断线显示琥珀待核，不把旧状态或未知状态冒充未收录/无PDF。点击单独重试按钮只执行这些只读核对。

## 0.4.0 服务与账号边界

新增服务全部独立保存密钥引用、模型及缓存，不自动猜测个人账号、不安装Easydict、不寻找其他应用凭据。Bing的临时匿名网页参数只用于当前请求，不写入设置或分发包；遇验证直接报错，不绕过限制。MyMemory为只读get请求，不调用公共记忆库set投稿。微软F0、DeepL API Free及任何AI赠送额度均需用户在账户核对，不将免费层标签作为无费用保证。

OpenAI的store=false限制该接口的响应持久化选项，不等于对服务方数据保留政策作出保证。云服务可能有日志、地区与留存要求，应按服务方当前条款判断。密钥请求不跟随重定向；网络代理/证书环境需本人配置，程序不会关闭TLS验证或私自装证书。

模型名和API区域为公开参数，用户仍需核对账户权限。诊断只读元数据不代表成功生成，协议模拟也不代表真实付费账号通过。本版没有账号级成本监控或并行加速；批次仍为手动串行，资源与费用选择由用户控制。

## Agent交接模板（0.4.1）

默认要求、研究背景及Prompt模板保存在本库data.json和上一版设置，不导出到可分享的主题profile或安装包。复制Prompt会把个人背景、选定论文摘要和可选任务位置写入系统剪贴板；仅粘贴给可信Agent，接收Agent/云模型的政策另行适用。模板不能读取Vault文件、密钥或执行代码，只替换五个允许的文本占位符。未知占位符/无论文占位符会被拒绝。

仅复制不写任务；保存并复制逐篇写入指定收件箱，不自动启动Agent或联网下载。文件写入成功与剪贴板成功分别回报。模板及背景变化生成新任务，不覆盖已有快照；旧v1任务保留。接收Agent拥有的文件、Zotero、代码执行权限由其环境管理，本插件的Prompt不是Agent沙箱，不代替授权检查。


## 0.4.3 Zotero专项Agent配置

Zotero配置Prompt仅含当前库名、本机端口和操作约定；复制不执行或联网。专门接口只接收enabled/port，使用统一revision和持久保存，其他设置保留。check仅在已启用后读取本机库并返回计数，附件检查沿用原有规则；不提供下载/写库能力。提示词不构成Agent权限沙箱。Zotero偏好和API开关由用户在Zotero界面确认，不扫描或改SQLite/偏好文件。见[专项指南](ZOTERO.md)。

## 反馈窗口的数据边界（0.4.5）

反馈窗口不自动读取或发送设置、日志、论文、Zotero 数据或密钥；自动附带字段仅为可见的插件版本、Obsidian 版本和系统类型。没有 GitHub Token、自动提交、后台遥测或后台反馈上传。

用户点击「在 GitHub 检查并提交」时，用户输入的标题/正文及上述环境字段通过 HTTPS URL 查询参数交给 GitHub；浏览器、历史记录和 GitHub 可能保留草稿，即使最后没有提交。复制草稿则进入系统剪贴板。先检查内容，勿填敏感信息；安全问题走私密报告通道。

长草稿不强塞进超长 URL，保留复制及手动提交入口。反馈未填写完整、浏览器失败或复制失败时，不显示“已提交”。公开反馈需要用户自己的 GitHub 登录，不向插件提供凭据。
