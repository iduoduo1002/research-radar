- 四个内置帮助窗口实际打开，均有完整正文与标题层级；不是空白占位。正文分别超过 4,200 / 2,000 / 3,400 / 1,200 字符（最后一份验收文档随后补充了本段）。
- 实际点击“检查连接与模型”，取得本机模型清单，包含 hy-mt2:latest；推理请求增量为 0。
- 实际点击翻译开关和底部“保存设置”，内存与磁盘回读均为开启。
- 实际点击“试译一句”，返回中文并保留47/50及仍需实验验证的限定。
- 实际勾选一篇 Emzing 论文（高分辨率 LC-MS 代谢组学软件，摘要1,842英文字符），点击批量翻译按钮，Hy-MT2成功返回标题和摘要并写入长期保存区。整个单篇流程约13.15秒，1次模型请求；仅是这篇的测量，不代表100篇吞吐量。
- 悬停和切换原文/中文的新增模型请求为0。重载后批次完成记录和译文仍在，模型请求计数为0。
- 分发包含10个明确文件，文档均非空、Markdown相对链接目标全部随包提供；没有个人data.json、任务或缓存。

测试库留在已启用本地翻译的状态，批次已完成，不会自动继续；新安装包的默认翻译开关仍关闭。本轮未改变日常工作库原Hearth雷达的程序、配置或固定MD文件。

原始证据位于开发项目 evidence/live-translation-021.json、live-paper-021.json、tests-021.txt。

## 尚未覆盖

- 未做 Windows/Linux 实机测试，移动端不支持；本机 Obsidian/macOS 测试不代表其他系统已通过。
- 独立版 Zotero 真实联通/PDF标记本轮未重测，沿用代码及既有规则，不能声称该链路完整验收。
- 本地模型只用短样本验证接口、译文结构和保存；未运行100篇性能基准、长文压力测试或重新做系统精度评审。
- 暂停/超时不保证中断 Ollama 已接收的当前推理。旧模型缓存可能继续显示。
- 论文任务仍只保存/复制；自动 Agent 启动、固定聊天同步、PDF下载和Zotero写入不在独立版实现范围。
- 没有独立安全审计，配置校验不是操作系统沙箱。

## 证据位置与复验

安装包带本记录和使用手册；开发项目的 evidence/ 保存原始测试结果，不将个人缓存或任务随包分发。维护者可运行 `npm test`、`npm run package`；用户按使用手册的“检查连接与模型 → 保存 → 试译一句 → 勾选一篇翻译 → 重启读回”复验自己的环境。

旧版0.2.0曾通过11项测试与历史列表/手动配置实测，但当时没有真实模型翻译验收、没有把安全说明和验收文档纳入安装包。这些交付缺口由本版补充，不能将旧版记录当成本版所有链路都已完成。
